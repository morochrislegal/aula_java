# aula_java
Preparando o ambiente: 
Para podermos rodar códigos em Java, são necessárias algumas instalações, como: Oracle Java e Visual Studio Code.
Com o ambiente preparado, os próximos passos são instalar as extensões necessárias e testar se o Java está funcionado. A extensão é: Extension Pack for Java. Essa extensão instala junto, o debugger e o autocomplete.
Para testar se o Java está funcionando precisamos:Abrir o terminal do windows (tecla windows + R -> digitar CMD na caixa qe abrir)
